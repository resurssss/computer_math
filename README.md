# Вычислительная математика (ИТМО)

Репозиторий с лабораторными работами по курсу «Вычислительная математика». Работы выполнены на Python.

## Содержание

| # | Файл | Тема |
|---|------|------|
| 1 | `1.py` | Решение СЛАУ методом Гаусса-Зейделя (диагональное преобладание, норма итерационной матрицы, сходимость) |
| 2 | `2.py` | Численные методы решения нелинейных уравнений (хорд, секущих, простой итерации) |
| 3 | `3.py` | Численное интегрирование (прямоугольники, трапеции, Симпсон; правило Рунге) |
| 4 | `4.py` | Метод наименьших квадратов: линейная, квадратичная, экспоненциальная, логарифмическая, степенная аппроксимация; S, δ, R², корреляция Пирсона |
| 5 | `5.py` | Интерполяция: Лагранж, Ньютон (разделённые разности), Гаусс (конечные разности) |

## Стек

- Python 3.x
- NumPy, Matplotlib

## Запуск

```bash
python 1.py
